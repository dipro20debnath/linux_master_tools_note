## 🔰 Introduction

### What is `cd`?
`cd` (short for **change directory**) is a shell built-in command that changes the current working directory. Unlike most commands, `cd` is NOT a separate binary — it's built directly into the shell (bash, zsh, etc.).

### Why is it a shell built-in?
If `cd` were an external program, it would run in a child process. When that child exits, the parent shell's directory would remain unchanged. Only a built-in can modify the shell's own working directory.

### History
- Originated in **Unix V6** (1975)
- POSIX standardized — works on every Unix-like system
- Every shell implements it: bash, zsh, sh, fish, csh

## 📖 Theory — How `cd` Works Internally

### Path Types
```
Absolute Path:  /home/dipro/Documents     ← Starts from root /
Relative Path:  Documents/notes           ← Relative to current directory
```

### Internal System Calls
1. Shell receives the `cd /path` command
2. Shell calls `chdir("/path")` system call
3. Kernel validates the path and permissions
4. Kernel updates the **current working directory (CWD)** in the process's task struct
5. The `$PWD` environment variable is updated
6. `$OLDPWD` stores the previous directory

### Key Concepts
- **`.`** — Current directory
- **`..`** — Parent directory
- **`~`** — Home directory (`$HOME`)
- **`-`** — Previous directory (`$OLDPWD`)
- **`$PWD`** — Current working directory variable
- **`$OLDPWD`** — Previous working directory variable
- **`$CDPATH`** — Search path for `cd` (like `$PATH` for commands)

## 🧰 Syntax & Options Reference

```bash
cd [OPTIONS] [DIRECTORY]
```

| Usage | Description |
|-------|-------------|
| `cd` | Go to home directory (`$HOME`) |
| `cd ~` | Go to home directory |
| `cd /path` | Go to absolute path |
| `cd path` | Go to relative path |
| `cd ..` | Go to parent directory |
| `cd ../..` | Go up two levels |
| `cd -` | Go to previous directory (toggle) |
| `cd ~username` | Go to another user's home |
| `cd -P` | Resolve symlinks (use physical path) |
| `cd -L` | Follow symlinks (logical, default) |

## 🟢 Basic Usage (Beginner)

### 1. Go to home directory
```bash
$ cd
$ pwd
/home/dipro

# OR
$ cd ~
$ pwd
/home/dipro
```

### 2. Navigate to a specific directory
```bash
$ cd /var/log
$ pwd
/var/log

$ cd /etc/apt
$ pwd
/etc/apt
```

### 3. Go to parent directory
```bash
$ pwd
/home/dipro/Documents/projects

$ cd ..
$ pwd
/home/dipro/Documents
```

### 4. Go up multiple levels
```bash
$ pwd
/home/dipro/Documents/projects/app

$ cd ../../..
$ pwd
/home/dipro
```

### 5. Relative path navigation
```bash
$ pwd
/home/dipro

$ cd Documents/notes
$ pwd
/home/dipro/Documents/notes
```

### 6. Go to previous directory (`cd -`)
```bash
$ cd /var/log
$ cd /etc
$ cd -        # Goes back to /var/log
/var/log
$ cd -        # Goes back to /etc (toggles)
/etc
```

## 🟡 Intermediate Usage

### 7. Navigate to another user's home
```bash
$ cd ~root
$ pwd
/root

$ cd ~www-data
$ pwd
/var/www
```

### 8. Using `$CDPATH` for quick navigation
```bash
# Set CDPATH (add to ~/.bashrc)
export CDPATH=".:/home/dipro:/home/dipro/projects"

# Now you can cd to any subdirectory of those paths
$ cd Documents    # Finds /home/dipro/Documents
$ cd webapp       # Finds /home/dipro/projects/webapp
```

### 9. Physical vs Logical path (`-P` vs `-L`)
```bash
# Create a symlink
$ ln -s /var/log /home/dipro/mylog

# Default (logical) — follows the symlink name
$ cd -L /home/dipro/mylog
$ pwd
/home/dipro/mylog

# Physical — resolves to actual path
$ cd -P /home/dipro/mylog
$ pwd
/var/log
```

### 10. Handling spaces in directory names
```bash
# Method 1: Quotes
$ cd "My Documents"

# Method 2: Escape spaces
$ cd My\ Documents

# Method 3: Tab completion (BEST!)
$ cd My<TAB>    # Auto-completes
```

### 11. Using environment variables
```bash
$ export PROJECT_DIR="/home/dipro/projects/webapp"
$ cd $PROJECT_DIR
$ pwd
/home/dipro/projects/webapp
```

## 🔴 Advanced Usage (Pro Level)

### 12. Directory stack with `pushd` / `popd`
```bash
# pushd — save current dir and change to new one
$ pushd /var/log
/var/log ~ 

$ pushd /etc/apt
/etc/apt /var/log ~

# View stack
$ dirs -v
 0  /etc/apt
 1  /var/log
 2  ~

# popd — go back to previous saved dir
$ popd
/var/log ~

$ popd
~
```

### 13. Auto-cd in Zsh/Bash
```bash
# In Zsh — just type directory name (no cd needed!)
# Enable in bash:
shopt -s autocd

# Now just type:
$ /var/log     # Same as: cd /var/log
$ ..           # Same as: cd ..
```

### 14. `cd` in subshell (doesn't affect parent)
```bash
$ pwd
/home/dipro

# Run in subshell
$ (cd /var/log && ls)   # Lists /var/log contents

$ pwd
/home/dipro            # Still in original directory!
```

### 15. Correcting typos automatically
```bash
# Enable in bash
shopt -s cdspell

$ cd /hom/dipro/Documetns
# Bash auto-corrects to: /home/dipro/Documents
```

### 16. `CDPATH` advanced setup
```bash
# ~/.bashrc
export CDPATH=".:~:~/projects:~/Documents:/etc:/var"

# Now from anywhere:
$ cd apt         # → /etc/apt
$ cd log         # → /var/log  
$ cd webapp      # → ~/projects/webapp
```

### 17. Bookmark directories with functions
```bash
# Add to ~/.bashrc
bookmark() { export "BM_$1"="$(pwd)"; }
goto() { cd "$(eval echo \$BM_$1)"; }

# Usage:
$ cd /var/log/apache2
$ bookmark apache     # Save bookmark
$ cd /                # Go somewhere else
$ goto apache         # Jump back to /var/log/apache2
```

## 🔗 Piping & Combining with Other Tools

```bash
# cd + command execution
$ cd /var/log && tail -f syslog

# cd in script (with error handling)
cd /target/dir || { echo "Failed!"; exit 1; }

# cd with find
$ cd "$(find /home -name 'project' -type d | head -1)"

# cd with fzf (fuzzy finder)
$ cd "$(find . -type d | fzf)"

# Subshell execution (preserves current dir)
$ (cd /var/log && grep "error" *.log)
```

## 💡 Real World Pro Tips

### Tip 1: Essential `~/.bashrc` setup
```bash
shopt -s autocd      # Type dir name without cd
shopt -s cdspell     # Auto-correct typos
shopt -s dirspell    # Auto-correct during tab completion
export CDPATH=".:~:~/projects"
```

### Tip 2: Use `z` or `zoxide` for smart navigation
```bash
# Install zoxide (smarter cd)
$ curl -sS https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | bash

# It learns your frequently visited directories
$ z proj        # Jumps to most visited dir matching "proj"
$ z log         # Jumps to /var/log if you visit it often
```

### Tip 3: Quick project switching
```bash
# Function for quick project cd
proj() { cd ~/projects/"$1" 2>/dev/null || echo "Project '$1' not found"; }

$ proj webapp
$ proj api-server
```

### Tip 4: Server admin quick navigation
```bash
alias logs='cd /var/log'
alias conf='cd /etc'
alias www='cd /var/www/html'
alias nginx='cd /etc/nginx'
```

## ✅ Pros & Cons

| ✅ Pros | ❌ Cons |
|---------|---------|
| Universal — works everywhere | No history tracking (use `pushd`) |
| Instant execution (built-in) | Can't cd into files (obviously) |
| Supports `~`, `-`, `..` shortcuts | No fuzzy matching (use `zoxide`) |
| `$CDPATH` for quick access | `cd` in scripts can cause issues |
| Tab completion support | Symlink confusion (`-P` vs `-L`) |

## 📍 Where & When to Use

| Scenario | Use `cd`? | Better Alternative |
|----------|-----------|-------------------|
| Basic navigation | ✅ Yes | — |
| Toggle between 2 dirs | ✅ `cd -` | — |
| Multiple dir history | ⚠️ Limited | `pushd`/`popd` |
| Frequent dir jumping | ❌ Slow | `zoxide`, `z` |
| In scripts | ✅ With error handling | `pushd`/`popd` |
| Complex project nav | ⚠️ Manual | `$CDPATH`, aliases |

## ⚠️ Common Mistakes & Troubleshooting

| Mistake | Fix |
|---------|-----|
| `cd: no such file or directory` | Check path, use tab completion |
| `cd: permission denied` | Need `x` (execute) permission on dir |
| cd in script doesn't persist | cd runs in subshell; use `source` |
| Spaces in dir name fail | Use quotes: `cd "My Dir"` |
| Symlink confusion | Use `cd -P` for physical path |
| `cd` without effect in script | Scripts run in child process |

### Fix: `cd` in sourced scripts
```bash
# ❌ Running script (new subshell)
$ ./go_to_project.sh    # cd doesn't persist

# ✅ Sourcing script (same shell)
$ source go_to_project.sh   # cd persists!
$ . go_to_project.sh        # Same thing
```
