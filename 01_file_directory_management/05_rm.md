## 🔰 Introduction

### What is `rm`?
`rm` (remove) deletes files and directories. It uses the `unlink()` system call to remove directory entries. **There is NO recycle bin** — deleted files are gone permanently.

### ⚠️ CRITICAL WARNING
```
rm -rf /     ← DESTROYS ENTIRE SYSTEM — NEVER RUN THIS!
rm -rf ~     ← DESTROYS YOUR HOME DIRECTORY
rm -rf *     ← DESTROYS EVERYTHING IN CURRENT DIRECTORY
```

---

## 🧰 Syntax & Options

```bash
rm [OPTIONS] FILE(s)
```

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-f` | `--force` | Force removal (no prompts, ignore nonexistent) |
| `-i` | `--interactive` | Prompt before every removal |
| `-I` | — | Prompt once before removing 3+ files |
| `-r` / `-R` | `--recursive` | Remove directories and contents recursively |
| `-d` | `--dir` | Remove empty directories |
| `-v` | `--verbose` | Print each file being removed |
| `--no-preserve-root` | — | Allow `rm -rf /` (NEVER use!) |
| `--preserve-root` | — | Refuse to remove `/` (**default**) |

## 🟢 Basic Usage (Beginner)

```bash
# Remove a single file
$ rm file.txt

# Remove multiple files
$ rm file1.txt file2.txt file3.txt

# Remove with confirmation
$ rm -i important_file.txt
rm: remove regular file 'important_file.txt'? y

# Force remove (no confirmation)
$ rm -f file.txt
```

## 🟡 Intermediate Usage

### Remove directories
```bash
# Remove empty directory
$ rm -d empty_dir
# OR
$ rmdir empty_dir

# Remove directory with ALL contents (CAREFUL!)
$ rm -r project_dir

# Remove directory forcefully (no prompts)
$ rm -rf old_project
```

### Verbose removal
```bash
$ rm -rv old_dir/
removed 'old_dir/file1.txt'
removed 'old_dir/file2.txt'
removed directory 'old_dir/'
```

### Pattern-based removal
```bash
# Remove all .log files
$ rm *.log

# Remove all .tmp files in current dir
$ rm -f *.tmp

# Remove all files starting with "temp"
$ rm temp*
```

### Interactive mode for safety
```bash
# Prompt for each file
$ rm -ri directory/
rm: descend into directory 'directory/'? y
rm: remove regular file 'directory/file1'? y
rm: remove regular file 'directory/file2'? n
rm: remove directory 'directory/'? y

# Prompt once (3+ files)
$ rm -I *.log
rm: remove 15 arguments? y
```

## 🔴 Advanced Usage

### Safe deletion with find
```bash
# Delete files older than 30 days
$ find /var/log -type f -mtime +30 -delete

# Delete empty files
$ find . -type f -empty -delete

# Delete files by size (larger than 100MB)
$ find /tmp -type f -size +100M -exec rm -v {} \;

# Delete all .cache files recursively
$ find . -name "*.cache" -type f -exec rm -v {} +
```

### Secure deletion (overwrite before removing)
```bash
# shred — overwrite file 3 times before removing
$ shred -vzu file.txt
# -v verbose, -z add zero pass, -u remove after

# Or with specific number of passes
$ shred -vzu -n 7 sensitive_data.txt
```

### Remove files with special characters in names
```bash
# File starting with dash
$ rm -- -strange-file.txt
$ rm ./-strange-file.txt

# File with spaces
$ rm "file with spaces.txt"
$ rm file\ with\ spaces.txt

# File with special chars
$ rm -- '$pecial_file'
```

### Protect against accidental rm
```bash
# Create an undeletable marker file
$ touch -- -i        # File named "-i"
# Now rm * will expand to: rm -i file1 file2 ...
# The -i flag triggers confirmation for each file!
```

## 🔗 Piping & Combining

```bash
# Remove files found by find
$ find /tmp -name "*.bak" | xargs rm -v

# Remove files from a list
$ cat files_to_delete.txt | xargs rm -v

# Remove all except specific files
$ ls | grep -v "keep_this" | xargs rm

# Remove empty directories recursively
$ find . -type d -empty -delete
```

## 💡 Real World Pro Tips

### Tip 1: Safer rm alias
```bash
# Add to ~/.bashrc — ALWAYS ask for confirmation on recursive delete
alias rm='rm -I --preserve-root'
```

### Tip 2: Use trash-cli instead
```bash
$ sudo apt install trash-cli
$ trash-put file.txt        # Moves to trash (recoverable!)
$ trash-list                # List trashed files
$ trash-restore             # Restore files
$ trash-empty               # Empty trash permanently

# Alias rm to use trash
alias rm='trash-put'
```

### Tip 3: Before running `rm -rf`, list first!
```bash
# ✅ FIRST check what you'll delete
$ ls /path/to/delete/
# Then if correct:
$ rm -rf /path/to/delete/
```

### Tip 4: Server log cleanup script
```bash
#!/bin/bash
# Delete logs older than 30 days
find /var/log -name "*.log" -mtime +30 -exec rm -v {} \;
echo "Old logs cleaned at $(date)" >> /var/log/cleanup.log
```

### Tip 5: The famous `rm -rf /` protection
```bash
# Modern Linux prevents this by default
$ rm -rf /
rm: it is dangerous to operate recursively on '/'
rm: use --no-preserve-root to override this failsafe

# But rm -rf /* is NOT protected! Be VERY careful!
```

## ✅ Pros & Cons

| ✅ Pros | ❌ Cons |
|---------|---------|
| Fast and efficient | **NO UNDO** — files gone forever |
| Powerful pattern matching | Easy to make catastrophic mistakes |
| Works recursively | No built-in trash/recycle bin |
| `-i` flag for safety | `rm -rf` can destroy systems |

## 📍 Where & When to Use

| Scenario | Recommended Approach |
|----------|---------------------|
| Delete single file | `rm file.txt` |
| Delete directory | `rm -r dir/` (careful!) |
| Cleanup old files | `find ... -delete` |
| Sensitive data | `shred -vzu file` |
| General use | `trash-put` (recoverable) |
| Scripts/automation | Always use full paths, double-check |

---

## ⚠️ Common Mistakes

| Mistake | Consequence | Prevention |
|---------|-------------|------------|
| `rm -rf /` | System destroyed | `--preserve-root` (default) |
| `rm -rf *` in wrong dir | All files deleted | Always `pwd` first |
| `rm -rf $VAR/` when `$VAR` is empty | Becomes `rm -rf /` | Use `${VAR:?}` |
| `rm *.txt` with spaces | Wrong files deleted | Quote patterns |
| Running rm as root | No permission safety | Use `rm -I` |

### Safe variable usage in scripts
```bash
# ❌ DANGEROUS — if $DIR is empty, becomes rm -rf /
rm -rf $DIR/

# ✅ SAFE — exits if $DIR is unset
rm -rf "${DIR:?Variable not set}/"
```

```
rm file           → Delete file         rm -d dir    → Empty dir
rm -f file        → Force (no prompt)   rm -r dir    → Dir + contents
rm -i file        → Interactive         rm -rv dir   → Verbose recursive
rm -rf dir        → Force recursive     rm -- -file  → Dash filename

```
