## 🔰 Introduction

`wc` (word count) counts lines, words, characters, and bytes in files. Default output shows all three: **lines, words, bytes**.

### What counts as what?
- **Line**: Terminated by newline `\n`
- **Word**: Sequence of non-whitespace characters
- **Character**: Depends on locale (multibyte support)
- **Byte**: Always single byte

---

## 🧰 Syntax & Options

```bash
wc [OPTIONS] [FILE(s)...]
```

| Flag | Long Form | Description |
|------|-----------|-------------|
| `-l` | `--lines` | Count lines |
| `-w` | `--words` | Count words |
| `-c` | `--bytes` | Count bytes |
| `-m` | `--chars` | Count characters (multibyte aware) |
| `-L` | `--max-line-length` | Length of longest line |

---

## 🟢 Basic Usage

```bash
# Default output: lines, words, bytes
$ wc file.txt
  42  310  2048  file.txt

# Count lines only
$ wc -l file.txt
42 file.txt

# Count words only
$ wc -w file.txt
310 file.txt

# Count bytes
$ wc -c file.txt
2048 file.txt

# Multiple files (with total)
$ wc -l *.txt
   42 file1.txt
   87 file2.txt
  123 file3.txt
  252 total
```

## 🟡 Intermediate Usage

### Count from stdin (pipe)
```bash
# Count files in directory
$ ls -1 | wc -l
15

# Count running processes
$ ps aux | wc -l

# Count matches in grep
$ grep -c "error" log.txt     # Better than grep | wc -l
# OR
$ grep "error" log.txt | wc -l

# Count unique lines
$ sort file.txt | uniq | wc -l
```

### Longest line length
```bash
$ wc -L file.txt
127 file.txt      # Longest line is 127 characters
```

### Characters vs Bytes
```bash
# ASCII file — same count
$ echo "Hello" | wc -c    # 6 bytes (includes \n)
$ echo "Hello" | wc -m    # 6 chars

# UTF-8 file — different!
$ echo "こんにちは" | wc -c    # 16 bytes
$ echo "こんにちは" | wc -m    # 6 chars (5 + newline)
```

## 🔴 Advanced Usage

### Code statistics
```bash
# Lines of code in project
$ find . -name "*.py" -exec wc -l {} + | tail -1
  4523 total

# Lines per file, sorted by size
$ find . -name "*.py" -exec wc -l {} + | sort -rn | head -10

# Non-empty lines of code
$ grep -cv "^$" *.py

# Count functions in Python files
$ grep -c "def " *.py
```

### Log analysis
```bash
# Count log entries per day
$ awk '{print $1}' access.log | sort | uniq -c

# Count 404 errors
$ grep -c "404" access.log

# Count unique visitors (IPs)
$ awk '{print $1}' access.log | sort -u | wc -l
```

### Security monitoring
```bash
# Count failed SSH attempts
$ grep -c "Failed password" /var/log/auth.log

# Count unique attacker IPs
$ grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort -u | wc -l

# Users in the system
$ wc -l /etc/passwd
```

### Script: File statistics report
```bash
#!/bin/bash
echo "=== File Statistics ==="
for f in "$@"; do
    lines=$(wc -l < "$f")
    words=$(wc -w < "$f")
    chars=$(wc -m < "$f")
    printf "%-20s Lines: %6d  Words: %6d  Chars: %6d\n" "$f" "$lines" "$words" "$chars"
done
```

## 🔗 Piping & Combining

```bash
# Count files by type
$ find . -type f -name "*.py" | wc -l

# Count directories
$ find . -type d | wc -l

# Count words in command output
$ man ls | wc -w

# Disk usage entry count
$ df | wc -l

# Empty lines count
$ grep -c "^$" file.txt
```

## 💡 Real World Pro Tips

1. **`wc -l < file`** (with redirect) doesn't print filename — cleaner for scripts
2. **`grep -c`** is better than `grep | wc -l` — one process instead of two
3. **`find ... | wc -l`** to count files matching criteria
4. **`wc -L`** helps find overly long lines (code style checking)
5. **Combine with `find -exec`** for project-wide stats

### Quick aliases
```bash
alias lines='wc -l'
alias words='wc -w'
alias chars='wc -m'
```

## ✅ Pros & Cons

| ✅ Pros | ❌ Cons |
|---------|---------|
| Dead simple to use | Very limited functionality |
| Multi-file with totals | No pattern-based counting |
| Multibyte character support | Counts all lines (no filtering) |
| Pipe-friendly | No formatting options |

---

## 📍 Where & When to Use

| Scenario | Use `wc`? | Alternative |
|----------|-----------|-------------|
| Count lines | ✅ `wc -l` | — |
| Count matches | ⚠️ Use `grep -c` instead | `grep -c` |
| Code line counting | ✅ Yes | `cloc` (advanced) |
| File size | ❌ Use `stat` or `ls -l` | — |
| Character analysis | ✅ `wc -m` | — |

## 🧠 Cheat Sheet

```
wc file          → lines words bytes    wc -m file   → Characters
wc -l file       → Lines only           wc -L file   → Longest line
wc -w file       → Words only           wc -l < file → No filename
wc -c file       → Bytes only           wc -l *.txt  → Multi-file + total

TIPS: grep -c "pat" file  (better than grep | wc -l)
      find . -name "*.py" -exec wc -l {} +  (project stats)
      wc -l < file  (clean output for scripts)
```
