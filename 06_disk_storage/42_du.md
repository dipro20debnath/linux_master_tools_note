## 🔰 Introduction

### What is `du`?
`du` (**D**isk **U**sage) estimates and reports the disk space used by files and directories by recursively walking the directory tree.

### `df` vs `du`:
| Feature | `df` | `du` |
|---------|------|------|
| Shows | Filesystem-level usage | Per-directory/file usage |
| Scope | Entire mounted filesystem | Specific directory tree |
| Speed | Instant (kernel data) | Slower (walks directory tree) |
| Use case | "How full is the disk?" | "WHAT is using the space?" |

---

## 🧰 Syntax & Options

```bash
du [OPTIONS] [PATH...]
```

| Flag | Description |
|------|-------------|
| `-h` | **Human-readable** (K, M, G) |
| `-s` | **Summary** — total only (no subdirectories) |
| `-S` | Separate — don't include subdirectory sizes |
| `-c` | Grand **total** at the end |
| `-a` | Show **all files** (not just directories) |
| `-d N` / `--max-depth=N` | Limit depth level |
| `--exclude=PATTERN` | Exclude matching files/dirs |
| `-x` | Stay on same filesystem |
| `-L` | Follow symbolic links |
| `--apparent-size` | Show file size, not disk usage |
| `-b` | Apparent size in bytes |
| `--time` | Show last modification time |
| `-0` | Null-terminated output |
| `--inodes` | Show inode usage instead |

## 🟢 Basic Usage

```bash
# Size of current directory
$ du -sh .
4.5G    .

# Size of specific directory
$ du -sh /var/log
2.1G    /var/log

# Multiple directories
$ du -sh /var /home /tmp
15G     /var
45G     /home
256M    /tmp

# Show subdirectory sizes (1 level deep)
$ du -h --max-depth=1 /var
1.2G    /var/log
800M    /var/cache
5.3G    /var/lib
120M    /var/tmp
7.4G    /var

# Show all files and directories
$ du -ah /home/dipro/project/ | head -20
```

## 🟡 Intermediate Usage

### Find largest directories (THE most useful pattern)
```bash
# Top 10 largest directories under /
$ sudo du -sh /* 2>/dev/null | sort -rh | head -10
45G     /home
15G     /var
8.2G    /usr
3.1G    /opt
1.5G    /snap
512M    /boot

# Drill deeper
$ sudo du -sh /var/* 2>/dev/null | sort -rh | head -10
5.3G    /var/lib
2.1G    /var/log
800M    /var/cache

# Even deeper
$ sudo du -sh /var/log/* 2>/dev/null | sort -rh | head -10
```

### Depth control
```bash
# Show 2 levels deep
$ du -h --max-depth=2 /home

# Show only top level (same as -s for each subdir)
$ du -h --max-depth=1 /home
```

### Exclude patterns
```bash
# Exclude node_modules and .git
$ du -sh --exclude='node_modules' --exclude='.git' ~/projects/*

# Exclude by pattern
$ du -sh --exclude='*.log' /var/

# Stay on same filesystem (don't cross mount points)
$ du -shx /
```

### With modification time
```bash
$ du -h --time /var/log/*.log
1.2G    2026-05-12 10:30    /var/log/syslog
450M    2026-05-11 23:59    /var/log/auth.log
```

### Grand total
```bash
$ du -sh -c /var/log /var/cache /var/lib
2.1G    /var/log
800M    /var/cache
5.3G    /var/lib
8.2G    total
```

## 🔴 Advanced Usage

### Disk Usage Audit Script
```bash
#!/bin/bash
# disk_audit.sh — Full disk usage report
echo "=== DISK USAGE AUDIT — $(date) ==="
echo ""
echo "=== TOP 10 DIRECTORIES ==="
sudo du -sh /* 2>/dev/null | sort -rh | head -10
echo ""
echo "=== TOP 10 LARGEST FILES ==="
sudo find / -type f -size +100M -exec ls -lh {} + 2>/dev/null | sort -k5 -rh | head -10
echo ""
echo "=== /var BREAKDOWN ==="
sudo du -sh /var/* 2>/dev/null | sort -rh | head -10
echo ""
echo "=== /home BREAKDOWN ==="
sudo du -sh /home/* 2>/dev/null | sort -rh
echo ""
echo "=== OLD LOG FILES (>30 days, >50MB) ==="
sudo find /var/log -name "*.log*" -size +50M -mtime +30 -exec ls -lh {} + 2>/dev/null
```

### Inode-heavy directory detection
```bash
# Find directories with most files (inode consumers)
$ sudo du --inodes -S / 2>/dev/null | sort -rn | head -10
```

### Compare apparent size vs disk usage
```bash
# Apparent size = actual data bytes
# Disk usage = blocks allocated (can differ due to block size, sparse files)
$ du -sh file.img
1.0G    file.img

$ du -sh --apparent-size file.img
500M    file.img
# Sparse file! Only 500MB of data in 1GB allocated space
```

### Security — Find unusual disk usage 🔒
```bash
# Large files in unusual locations
$ sudo find /tmp /dev/shm /var/tmp -type f -size +10M 2>/dev/null

# Hidden directories consuming space
$ sudo du -sh /.*  2>/dev/null | sort -rh

# Files modified recently (possible data exfiltration staging)
$ sudo find / -type f -size +100M -mtime -1 2>/dev/null
```

### Modern alternatives
```bash
# ncdu — interactive disk usage viewer (RECOMMENDED)
$ sudo apt install ncdu
$ sudo ncdu /
# Navigate with arrows, enter to drill down, d to delete

# dust — modern du replacement (Rust-based)
$ dust /var
```

## 🔗 Piping & Combining

```bash
# Top 10 directories sorted by size
$ du -sh /home/*/ 2>/dev/null | sort -rh | head -10

# Find user consuming most disk space
$ sudo du -sh /home/*/ | sort -rh

# Directories larger than 1GB
$ du -h --max-depth=1 / 2>/dev/null | grep -E '^\s*[0-9]+G'

# Export to CSV
$ du -sb /home/*/ 2>/dev/null | sort -rn | awk -F'\t' '{printf "%s,%.2f GB\n", $2, $1/1073741824}'

# Monitor directory growth
$ watch -n 60 'du -sh /var/log'
```

## 💡 Real World Pro Tips

### Tip 1: The disk space investigation workflow
```bash
# Step 1: Which filesystem is full?
$ df -h

# Step 2: What's using space at top level?
$ sudo du -sh /* 2>/dev/null | sort -rh | head

# Step 3: Drill into the biggest directory
$ sudo du -sh /var/* 2>/dev/null | sort -rh | head

# Step 4: Keep drilling until you find the culprit
$ sudo du -sh /var/log/* 2>/dev/null | sort -rh | head
```

### Tip 2: Use `ncdu` for interactive exploration
```bash
$ sudo ncdu /    # Visual, interactive — the BEST way
```

### Tip 3: Suppress permission errors
```bash
$ du -sh /path 2>/dev/null     # Clean output
```

### Tip 4: Watch directory growth in real-time
```bash
$ watch -n 5 'du -sh /var/log/app.log'
```

## ✅ Pros & Cons

| ✅ Pros | ❌ Cons |
|---------|---------|
| Per-directory breakdown | Slow on large filesystems |
| Depth control | High I/O on spinning disks |
| Exclude patterns | Permission errors without sudo |
| Grand total option | No real-time monitoring |
| Human-readable output | Counts hard links once |

## 📍 Where & When to Use

| Scenario | Command | Alternative |
|----------|---------|-------------|
| Find space hog | `du -sh /* \| sort -rh` | `ncdu` |
| Directory size | `du -sh dir/` | `ls -lh` (files only) |
| Project size | `du -sh --exclude=node_modules` | — |
| Disk audit | Script with `du` + `find` | Monitoring tools |
| Interactive browse | — | `ncdu` |

---

## ⚠️ Common Mistakes

| Mistake | Fix |
|---------|-----|
| Running without sudo | `sudo du -sh /var/*` |
| Forgetting `-h` (shows blocks) | Always use `-h` |
| Too deep recursion (slow) | Use `--max-depth=1` |
| Not suppressing errors | Add `2>/dev/null` |
| Confusing du output with df | du=per-dir, df=per-filesystem |

## 🧠 Cheat Sheet

```
du -sh dir/              → Directory total size
du -sh /*                → Top-level breakdown
du -h --max-depth=1 dir/ → One level deep
du -sh * | sort -rh      → Sorted by size (largest first)
du -ah dir/ | sort -rh   → All files sorted
du -sh -c dir1 dir2      → Multiple dirs + total
du -sh --exclude='.git'  → Exclude pattern

WORKFLOW:
  1. df -h                          → Find full filesystem
  2. sudo du -sh /* | sort -rh      → Find big directory
  3. sudo du -sh /var/* | sort -rh  → Drill deeper
  4. Repeat until found!

ALTERNATIVES:
  ncdu /                 → Interactive (best!)
  dust /var              → Modern Rust replacement
```
